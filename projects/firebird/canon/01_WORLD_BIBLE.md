# WORLD BIBLE — ERYNDOR

## 대륙
이야기의 무대는 **에리도르(Eryndor)** 대륙이다.

현재 대륙은 네 왕국으로 나뉘지만, 약 천 년 전에는 단 하나의 왕국 **아르카디아(Arcadia)** 아래 통일되어 있었다.

## 네 왕국
- **SKELDRIA** — 북부 / 백색 늑대 / 겨울 / 생존 / 군사
- **DRAEVOR** — 서부 / 검은 용 / 산맥 / 철 / 광산 / 제련
- **LYSARA** — 동부 / 은빛 해룡 / 바다 / 절벽 / 폭풍 / 기억
- **AUREVIA** — 남부 / 황금 불새 / 풍요 / 신앙 / 왕권 / 숨겨진 거짓말

## 고대 아르카디아
아르카디아는 최초의 통일 인간 왕국이었다.
당시 인간과 신수의 관계는 “지배”가 아니라 “균형”이었다.

### 최초의 계약
> 인간은 세계를 소유하지 않는다. 잠시 살아갈 뿐이다.

또한:
> 하나의 생명을 하나가 짊어지지 말라.

## 천 년 전의 대멸망
마지막 아르카디아 왕 **아에론 4세(Aeron IV)**는 네 신수의 힘을 인간 왕권 아래 통합하려 했다.
그 도구가 **재의 왕관(The Crown of Ash)** 이었다.

왕관이 완성되자 균형이 무너졌다.
- 북방에 계절을 벗어난 겨울
- 서부 산맥의 화산 폭발
- 동부의 거대한 범람
- 마지막으로 불새 아우레온의 귀환

불새는 망가진 세계를 “구한” 것이 아니라, 이미 죽은 질서를 태워 재생의 가능성을 만들었다.

## 왜 역사가 왜곡되었는가
대멸망 이후 살아남은 네 인간 지도자는 각 왕국의 창건자가 되었다.
그들은 자신들의 책임을 숨기기 위해 역사를 바꿨다.

공식 역사:
> 네 영웅이 신수의 축복을 받아 세계를 구했다.

실제 역사:
> 인간이 신수의 힘을 소유하려 했고 세계가 붕괴했다.

## 현재 세계가 다시 무너지는 이유
천 년 동안 네 왕국은 각자의 방식으로 신수의 힘을 이용했다.

- 스켈드리아: 겨울 / 생존의 힘을 군사적으로 이용
- 드라에보르: 용의 불과 광물을 전쟁 산업으로 이용
- 리사라: 바다의 기억으로 과거와 미래에 접근
- 아우레비아: 불새 신화를 왕권과 종교의 정당성으로 이용

## 세계 붕괴의 징조
- 스켈드리아: 겨울이 길어진다
- 드라에보르: 화산이 깨어난다
- 리사라: 바다가 비정상적으로 물러나거나 밀려온다
- 아우레비아: 죽은 땅이 늘어난다

## 핵심 세계 질문
