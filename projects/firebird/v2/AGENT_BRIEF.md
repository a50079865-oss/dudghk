# 집필 에이전트 공통 지침 — 《불새의 왕국》 EP02~EP08

## 0. 절대 규칙

1. **세계·인물·사건을 발명하지 마라.** 아래 진실 원천에 없는 설정을 만들면 폐기된다. 필요한 것은 전부 이미 정해져 있다.
2. **네 회차만 써라.** 다른 회차의 사건을 앞당기거나 미루지 마라.
3. **형식은 `PIPELINE_S2_EP01.md`를 그대로 따른다.** 48 CUT × 15초. 한 컷도 빠짐없이 `장소 / 핵심 목적 / 카메라 / 본문 시나리오 / 컷 종료 이미지`.
4. **구조 지점은 고정이다.** 네 회차에 배정된 핀치·구성점·미드포인트는 **반드시 지정된 CUT 근처에** 놓아라.
5. 결과물은 **파일 하나**로만 쓴다: `projects/firebird/v2/PIPELINE_S2_EP0N.md`. 다른 파일을 수정하지 마라. git 커밋하지 마라.

## 2. 반드시 지킬 작법 사항

### 두 주인공의 거짓말 (모든 대사의 뿌리)
- **엘라라 — "내 목숨은 다른 사람 목숨보다 싸다."** 자기를 셈에서 뺀다. 시그니처: *"저는 안 세요."*
- **리븐 — "숫자가 큰 쪽이 옳다."** 사람을 숫자로 센다. 시그니처: *"이백이다."*
- 두 거짓말은 **한 사람을 셈에서 지운다. 방향만 반대다.**

### 지배 아이디어
> **불새는 왕국을 구하러 온 것이 아니라, 인간이 다시 살아갈 자격이 있는지 확인하러 왔다.**
> 전제: **인간은 대가를 한 사람에게 몰아줄 때 자격을 잃는다.**

### 금기 (1순위 · 위반 시 폐기)
**뻔한 클리셰.** 판정 기준 = **「다음 컷 맞히기」 테스트** — 관객이 다음에 올 것을 맞힐 수 있으면 그 컷은 다시 써라.
금지 목록: 첫눈에 반함 · 밀쳐서 대신 맞고 죽기 · 치료하다 정체 발각 · 마을 볼모 협박 · 광신 신관 · 질투형 연적 · *"네가 그 사람이었구나"* 류의 인식 확인 대사 · 죽어가며 하는 긴 유언 · 감정의 이름을 부르는 대사(사랑해/미안해/보고 싶었어).

### 2순위 금기 — 신파
적립을 초과하는 감정 금지. **미어짐의 순간에 인물이 덜 느낀다.** 감정은 표정·자세·손동작으로.

### 대사
- 8분당 50~70줄 기준 → **12분이면 75~100줄.** 대사를 아끼지 마라(이전 실패 원인).
- 감정의 이름을 부르지 않는다. **사실·요구·거래**를 말한다.
- 기한·위치·숫자 같은 인과는 **반드시 말로 확정한다** (스릴러).
- 설명은 신관·왕·관리의 입으로. 주인공이 자기 세계를 설명하지 않는다.

### B스토리 — 요란 (19, 스켈드리아 부상병)
**「셈에서 지워진 한 사람」의 육화.** EP01에서 리븐이 *이백 대 하나*로 세고 버렸고, 엘라라가 살렸다.
말이 거의 없다. 누운 채·앉은 채 눈으로만 반응한다. **관객은 그를 통해 센다.**

## 3. AI 영상 생성 제약 (반드시 준수)

- **복잡한 격투 합 금지.** 큰 동작만 — 달리기·점프·회피·돌진·내려찍기·착지·밀려남·다시 일어남·충격파·빛의 폭발.
- **컷당 주요 인물 최대 2인.** 군중·군대는 **실루엣/부감**으로만.
- **대규모 전투는 「한 컷의 큰 그림 + 나머지는 작은 것」**으로. 말발굽·깃발·재·한 사람의 얼굴로 규모를 만든다. (규모 대비)
- 각 CUT에 **카메라 구도와 움직임을 반드시** 쓴다. 액션 구간에는 **Z축**(전진/후퇴/상승/급강하/오빗/임팩트 풀백)을 넣는다.
- 장소가 바뀌면 **전환 원인을 화면에 보여준다.**
- **NO BGM. SFX only.**
- 생성 난이도가 높다고 판단되는 컷은 본문 끝 자체 검토표에 **「주의 컷」으로 표시**한다.

## 4. 출력 형식 (EP01과 동일)

```
# 2단계 — 서술형 시나리오 원본 (AI 영상툴용)

**제목:** 《불새의 왕국》 EP0N — 「제목」
**장르:** 에픽 중세 하이판타지 · 스릴러/느와르 · 몰입형 멜로드라마
**러닝타임:** 12분 (CUT01~CUT48 · 15초 단위) · 시즌 내 위치 M:00–M:00
**구조:** (한 줄)

## CUT01 / 0:00–0:15
### 소제목
**장소:**
**핵심 목적:**
**카메라:**
본문 시나리오 (대사는 **인물** — "대사" 형식)

```

마지막에 **자체 검토표**(사건 흐름 / 동작 개연성 / 장소 전환 / 감정 변화 / 카메라 / Z축 / AI 친화성 / 캐릭터 수 / 컷 종료 / 대사 줄 수 / 주의 컷)를 붙인다.
