# [취향 프로파일] v0

## 1. 남길 목표 감정

> **"마지막에 가슴이 미어지면서 다음 화가 궁금한 것."**

두 가지를 한 회 끝에서 동시에 요구한다. 설계 원칙:

- **미어짐은 적립이 있어야 하고, 궁금함은 감춰야 생긴다.**
- 따라서 **클리프행어가 미어짐과 별개로 붙으면 안 된다.** 감정의 타격이 곧 다음 질문이어야 한다.
- 📚 *"적립 없는 환급은 뜬금포다"* — 울리려면 먼저 쌓는다.

## 2. 미어짐의 종류 — **엇갈림**

다섯 갈래(엇갈림 / 희생 / 오해 / 잃음 / 선택) 중 **엇갈림** 확정.

**구조적 귀결 — 이것이 이 작품의 엔진이다.**

1. **극적 아이러니가 필수.** 관객이 인물보다 많이 알아야 아프다.
   - 관객도 같이 모르면 → 그냥 사건
   - 관객만 알면 → *"지금 돌아봐"* 가 되고, 못 견디게 된다
2. **평행 구조가 무기가 된다.** 두 인물을 번갈아 보여주되, **같은 시간·같은 지도 위에 있다는 것을 관객만 알게** 한다.
   - ⚠️ 이전 1부도 평행 구조였으나 관객이 두 인물에 대해 아는 것이 없어 *따로 노는 두 갈래*로 읽혔다. 구조가 틀린 게 아니라 **아이러니가 없었다.**
3. **거리가 읽혀야 한다.** *"반 리밖에 안 떨어졌는데"* 를 관객이 느끼지 못하면 엇갈림도 없다.

## 3. 반응하는 원리 — 반지의 제왕 「연출 · 스펙터클」

표면을 베끼지 않고 원리만 추출한다.

| 원리 | 내용 | 이 작품에 적용 |
|---|---|---|
| **규모 대비** | 스펙터클이 먹히는 이유는 크기 자체가 아니라 **큰 것과 작은 것을 붙여놓기** 때문. 반지 하나·손 하나·얼굴 하나 다음에 산맥과 군대 | 작은 것이 걸려 있어야 큰 것이 무섭다. 인서트 → 와이드의 낙차를 설계 단위로 쓴다 |
| **지리의 가독성** | 누가 어디 있고 얼마나 떨어져 있는지 관객이 **항상** 안다. 지도를 보여주고 카메라가 그 거리를 건너간다 | **엇갈림과 같은 편이다.** 거리가 읽혀야 엇갈림이 아프다 |
| **카메라가 움직이고 세계가 크다** | 크레인·항공 리빌, 프레임이 열린다 | 이전 제작물은 인물 주변만 보여주고 세계를 보여주지 않았다 |
| **음악이 감정을 공개적으로 운반** | 절제하지 않는다 | 이전의 No-BGM 원칙은 이 취향과 충돌한다 — 재검토 대상 |

> ⚠️ **이전 1부에 없던 것:** 마을과 능선이 서로 어디쯤인지 한 번도 보여주지 않았다. 두 갈래가 **같은 지도 위에 있지 않았다.**

## 4. 금기 — **신파**

**정의(작업용):** 신파 = **적립을 초과하는 감정**. 쌓은 것보다 크게 환급하려 할 때 생긴다.

**엇갈림은 신파로 미끄러지기 가장 쉬운 장치다.** 따라서 다음을 규칙으로 고정한다.

| 규칙 | |
|---|---|
| **엇갈림은 우연이 아니라 선택으로 만든다** | *"조금만 일찍 돌아봤으면"* 을 우연으로 처리하면 신파. 인물이 **스스로 등을 돌려서** 못 만나야 비극이다. 관객은 그 문이 닫히는 것을 본다 |
| **미어짐의 순간에 인물이 덜 느낀다** | 인물이 다 울어버리면 관객은 구경만 한다. 관객이 인물보다 많이 알고 많이 느끼게 둔다 |
| **감정을 말로 설명하지 않는다** | 단, 절제 자체가 목적이 되어서는 안 된다(이전의 실패). 말은 하되 **감정의 이름을 부르지 않는다** |
| **고난을 쌓아 동정을 구하지 않는다** | 불행의 양이 아니라 **원인의 명확함**이 감정을 만든다 |

## 5. 장르 간 긴장 — 의식적으로 관리할 것

사용자가 고른 조합에는 서로 당기는 힘이 있다. 숨기지 않고 적어둔다.

- **몰입형 멜로 ↔ 신파 금지** — 감정은 크게, 표현은 작게. 적립을 충분히 한 뒤 환급의 순간에 절제한다.
- **스릴러의 촘촘한 인과 ↔ 느와르의 모호함** — 사건의 인과는 명확하게, **인물의 도덕은 모호하게.**
- **스펙터클 ↔ 유튜브 회차** — 규모는 필요하지만 회차마다 대형 장면을 넣을 수는 없다. **한 회에 하나의 큰 그림**을 원칙으로 배분한다.

# 관계 구조 (S1 인터뷰에서 확정)

| 항목 | 확정 |
|---|---|
| 시작 관계 | **서로 모른다 — 관객만 안다** |
| 엇갈림의 엔진 | **명령·의무** |
| 의무의 구조 | **서로를 죽이라는 명령** |
| 식별 방법 | **몸의 표식** (옷 아래 숨겨져 있다) |

**이 네 줄이 작품 전체를 결정한다.**

표식으로만 알아본다는 것은 **표적을 확인하려면 가까워져야 한다**는 뜻이다. 옷을 벗기거나, 다치게 하거나, 죽여야 보인다. 그래서 **사냥과 친밀함이 같은 동작**이 된다 — 구조가 스스로 멜로를 만들고, 동시에 매 장면을 스릴러로 만든다.

> **파생 규칙:** 둘 다 표식이 있어야 서로를 표식으로 찾을 수 있다. 따라서 **불새는 한 사람을 고르지 않았다.**

# S2 — 전제 · 로그라인 ★

## 전제 (Premise)

> **불새는 한 사람을 고르지 않았다. 둘을 골랐다.**
> **그리고 두 나라는 각자의 표식자에게 같은 명령을 내렸다 — 상대를 먼저 죽여라.**

세상에서 자기와 같은 존재는 단 한 사람인데, **그 한 사람이 자기가 죽여야 할 사람**이다.

## 로그라인

> 전쟁 3년째, 불새의 표식이 적대하는 두 나라의 두 사람에게 같은 밤 내린다.
> 각자의 나라는 그들에게 **상대를 먼저 죽이라** 명하지만, 둘은 서로의 얼굴을 모르고
> **옷 아래 숨은 표식으로만** 알아볼 수 있다 — 서로를 찾는 유일한 방법은 **가까워지는 것**이다.

## 이 전제가 취향 프로파일을 어떻게 충족하는가

| 요구 | 충족 방식 |
|---|---|
| **엇갈림** | 둘은 계속 스쳐 지나간다. 관객은 매번 안다 |
| **극적 아이러니** | 관객만 둘 다의 표식을 봤다. 인물은 눈앞의 사람이 표적인 줄 모른다 |
| **신파 금지** | 못 만나는 이유가 우연이 아니라 **매번 누군가가 명령을 택하기 때문** |
| **스릴러의 인과** | 표식을 확인하려면 가까워져야 한다 — 모든 접근이 곧 위험 |
| **느와르의 모호함** | 둘 다 살인 명령을 수행 중이다. 어느 쪽도 결백하지 않다 |
| **몰입형 멜로** | 사냥의 동작과 사랑의 동작이 물리적으로 같다 |
| **지리의 가독성** | 서로를 찾는 이야기이므로 **거리가 곧 서스펜스**다. 지도를 보여줄 이유가 생긴다 |
| **규모 대비** | 옷깃 아래 표식(작음) ↔ 두 나라의 전쟁(큼). 가장 작은 것이 가장 큰 것을 움직인다 |

## 표식이 무엇인가 — 확정

> **둘이 만나면 무언가 일어난다.**

표식은 힘도 저주도 아니다. **조건**이다. 두 사람이 만나는 순간에만 작동한다.

**따라서 만남 자체가 사건이고, 엇갈림이 곧 플롯이다.** 두 나라가 상대의 표식자를 죽이려는 이유도 여기서 나온다 — 무엇이 일어나는지에 대해 **두 나라가 서로 다른 것을 믿고 있고, 둘 다 틀렸을 수 있다.**

| | 믿는 것 | 그래서 |
|---|---|---|
| 한쪽 | 둘이 만나면 **세상이 탄다** | 만나기 전에 없애라 |
| 다른 쪽 | 둘이 만나면 **한쪽이 전부를 가진다** | 우리 쪽이 살아남게 하라 |

같은 명령이 나오지만 이유가 반대다. **어느 쪽도 진실을 모른다** — 이것이 느와르의 자리다.

# S3 — 인물 (초안)

> **이름은 가칭이다.** 이전 캐논의 이름을 임시로 빌렸을 뿐, 인물 자체는 새로 세웠다. 바꾸셔도 된다.

## A — 엘라라 (가칭)

| | |
|---|---|
| **Want** (원하는 것) | **표식을 없애고 싶다.** 선택받았다고 느끼지 않는다 — 낙인찍혔다고 느낀다 |
| **Need** (필요한 것) | 표식이 자기가 누구인지 **정하게 두지 않는 것.** 스스로 정하는 것 |
| **Lie** (믿는 거짓) | **"나는 아무것도 안 했다. 이건 내 잘못이 아니다."** — 수동성. 자기에게 일어난 일의 저자가 자기가 아니라고 믿는다 |
| **Wound** (상처) | 살자고 누군가를 두고 왔다. 그때도 **선택이 아니었다고** 스스로에게 말했다 |

**Lie가 엔진을 돌리는 방식:** 그녀가 "내 잘못이 아니다"를 붙들고 있는 한, 명령을 따르는 것도 자기 책임이 아니다. 그래서 계속 따른다. 그래서 계속 엇갈린다.

## B — 리븐 (가칭)

| | |
|---|---|
| **Want** | **명령을 완수하고 끝내는 것.** 빨리 끝날수록 덜 죽는다고 믿는다 |
| **Need** | 명령 **바깥에서** 자기 판단으로 한 번 서는 것 |
| **Lie** | **"내가 안 하면 더 나쁜 사람이 한다."** — 책임 회피의 가장 세련된 형태. 자기가 하는 것이 자비라고 믿는다 |
| **Wound** | 명령을 따랐다가 누군가를 잃었다. **그게 옳았다고 믿어야만** 지금까지 살 수 있었다 |

**Lie가 엔진을 돌리는 방식:** 그가 "내가 아니면 더 나쁜 사람이"를 붙들고 있는 한, 손을 떼는 것이 오히려 무책임이 된다. 그래서 계속 쥔다. 그래서 계속 엇갈린다.

## 두 Lie가 마주 보는 방식

둘의 거짓말은 **같은 거짓말의 앞뒤**다.

- 엘라라: *"나는 하지 않았다"* — 행위를 부인한다
- 리븐: *"내가 해야 한다"* — 행위를 독점한다

둘 다 **자기가 선택하고 있다는 사실을 견디지 못한다.** 한쪽은 선택을 없는 것으로 만들고, 한쪽은 선택을 의무로 만든다.

> **주제의 자리:** 이 작품이 증명해야 하는 것은 *"선택하지 않는 것도 선택이다"* 이고, 두 인물은 정반대 방향에서 같은 도망을 치고 있다. 서로를 알아보는 순간이 곧 **자기 거짓말을 알아보는 순간**이어야 한다.

# S4 — 3막 · 구성점 골격

## 지배 아이디어 (controlling idea)

> **사람은, 자기가 선택하고 있다는 사실을 끝까지 부인할 때 서로를 잃는다.**

두 인물의 Lie가 정확히 이것이다. 한쪽은 *"나는 하지 않았다"*, 한쪽은 *"내가 해야 한다"* — 둘 다 선택의 저자이기를 거부한다. **그 거부가 둘을 갈라놓는 힘이다.**

## 핵심 가치 축

| 축 | 1막 시작 | 3막 끝 |
|---|---|---|
| **구조 축** | 명령 (+) / 선택 (−) | 뒤집힌다 |
| **감정 축** | 혼자 (+) / 함께 (−) | 뒤집힌다 — 그러나 너무 늦게 |

막마다 부호가 뒤집히지 않으면 그 막은 정지다.

## 골격 (25 / 50 / 75)

```
콜드오픈 (0%)   │ ★결과 선공개 — 파국을 먼저. 얼굴은 감춘다
1막 (~25%)      │ 표식이 내린 밤 [도발적 사건]
                │   → 각자 명령을 받는다
                │   → [구성점1] 둘 다 명령을 받아들이고 상대를 찾아 나선다
                │      ※ 되돌릴 수 없는 문 = "찾겠다"고 말한 순간
2막 (~50%)      │ 상승하는 장애물 — 계속 스쳐 지나간다 (관객만 안다)
                │   → [핀치1 37.5%] 적대세력 상기 — 감시자가 붙는다
                │   → [미드포인트 50%] ★둘이 만난다. 서로를 모른 채
                │      · 거짓 승리: 함께 있는 것이 좋다
                │      · 수동→능동: 쫓기던 쪽이 먼저 움직인다
                │      · 판돈↑ 시간제한: 명령에 기한이 붙는다
                │   → [핀치2 62.5%] 한쪽이 상대를 의심하기 시작한다
                │   → [구성점2 75%] ★한쪽만 표식을 본다. 그리고 말하지 않는다
3막 (~25%)      │ [위기] 아는 쪽이 선택해야 한다 — 죽일 것인가, 말할 것인가
                │ [절정] ★급전 + 인식이 한 컷에
                │        모르던 쪽이 알아보는 순간 = 판이 뒤집히는 순간
                │        = 콜드오픈에서 본 그 장면
                │ [해소] 미어짐 + 다음을 여는 질문
```

## 각 지점의 설계 근거

### 콜드오픈 — 결과 선공개
파국을 먼저 박되 **얼굴을 감춘다.** 손, 표식, 불, 거리 — 그것만 보여준다.

> ⚠️ **절대 규칙:** 콜드오픈이 *누구인지*를 알려주면 표식-인식 엔진이 통째로 죽는다. 보여주는 것은 **무엇이 일어났는가**이고, 감추는 것은 **누구에게 일어났는가**다.

관객의 질문이 `무엇이 일어날까` → **`어떻게 저기까지 가는가`** 로 바뀐다.

### 구성점 1 — "찾겠다"고 말한 순간
되돌릴 수 없는 문은 **명령을 받은 순간이 아니라 받아들인 순간**이다. 받는 것은 수동이고, 받아들이는 것은 선택이다. **지배 아이디어가 첫 번째로 시험되는 자리.**

### 미드포인트 — 둘이 만난다, 서로를 모른 채
플레이북이 요구하는 세 가지를 전부 충족한다.

- **거짓 승리**: 함께 있는 것이 좋다. 관객은 그것이 최악이라는 것을 안다
- **수동 → 능동**: 지금까지 쫓기고 찾던 것에서, 먼저 움직이는 쪽이 생긴다
- **판돈 ↑ + 시간제한**: 명령에 기한이 붙는다

> 이 지점이 **작품 전체의 중심**이다. 관객은 여기서 처음으로 둘이 같은 프레임에 있는 것을 보고, 동시에 콜드오픈을 기억한다.

### 구성점 2 — 한쪽만 알아본다
**비대칭 지식이 3막의 엔진이다.**

표식을 본 쪽은 이제 *명령*과 *사람*을 같은 손에 들고 있다. 말하지 않는 것이 곧 매 순간의 선택이 된다 — 지배 아이디어가 가장 아프게 작동하는 구간.

관객은 한 사람이 아는 것을 알고, 다른 사람이 모르는 것을 안다. **극적 아이러니의 최대치.**

### 절정 — 급전 + 인식을 한 컷에
📚 *"정체가 드러나는 순간이 곧 판이 뒤집히는 순간이 되도록."*

모르던 쪽이 표식을 보는 순간과, 상황이 돌이킬 수 없게 되는 순간이 **같은 컷**이어야 한다. 따로 놓으면 설명이 되고, 겹치면 타격이 된다.

그리고 이 컷이 **콜드오픈에서 이미 본 장면**이다. 관객은 처음부터 이 그림을 알고 있었고, 이제 그 안에 있는 두 사람이 누구인지 안다. **같은 그림이 두 번째에 미어진다.**

## 신파 방어 점검

| 위험 | 방어 |
|---|---|
| 둘이 못 만나는 게 우연처럼 보인다 | 매 엇갈림은 **누군가 명령을 택한 결과**다. 관객이 그 선택을 본다 |
| 알아보는 순간 울음으로 간다 | **인물이 덜 느낀다.** 급전이 동시에 터지므로 울 시간이 없다 |
| 파국이 갑자기 온다 | 콜드오픈에서 이미 봤다. 적립은 첫 프레임부터 시작됐다 |

## 아직 정하지 않은 것

- **회차 수와 회당 분량** — 위 골격은 시즌 전체 기준. 회차 배분은 S5(비트시트)에서
- **파국의 내용** — 콜드오픈에 무엇이 보이는가 (S5에서 확정)
- 두 나라의 이름·지리 — 세계관은 시나리오 확정 후
