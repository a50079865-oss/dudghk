## CUT48 / 11:45–12:00
### 등불 하나 ★★

**장소:** 왕궁 방 창가 / 네리스 항구
**핵심 목적:** **회말 훅.** 그녀는 이미 기울었다. 다음 회차가 이것을 받는다
**카메라:** 창가 뒷모습 → 어깨 너머 항구 망원 → 등불 인서트 → 얼굴 홀드 → 암전

밤. 엘라라가 창가에 선다. 항구에 배들이 전부 불을 껐다. 딱 한 척만 등불을 켜놓았다 — **잿빛 돛의 작은 배.** 떠나지 않았다. 카메라가 그 등불을 망원으로 당긴다. 흔들리지 않는다. 다시 엘라라의 얼굴로 돌아온다. 그녀는 움직이지 않는다. 눈을 깜빡이지 않는다. 아주 오래 본다.
저 아래 복도에서 리븐의 발소리가 지나간다. 그녀는 돌아보지 않는다.

**컷 종료 이미지:** 어두운 항구에 켜져 있는 단 하나의 등불과, 창유리에 비친 엘라라의 얼굴이 겹쳐지는 프레임. 컷, 암전.

## 「다음 컷 맞히기」 자체 테스트

| 관객이 예상할 것 | 실제로 온 것 |
|---|---|
| 함대가 나타났으니 두 주인공을 공격한다 | 함대는 그녀를 **산 채로** 원한다. 공격은 **깃발 없는 제3세력**이 한다 |
| 위기에 몰리면 그녀가 불새의 힘을 쓴다 | **쓰지 않는다.** 그리고 사람이 열한 명 죽는다 — 그래서 더 나쁘다 |
| 함대전은 충각·화공·백병전으로 끝난다 | **바다가 끝낸다.** 인간은 아무것도 결정하지 못했다 |
| 습격자가 그녀를 죽이려 달려든다 | 무기 없이 **무릎을 꿇고** *"성녀여"* 라고 부른다 |

| 예언은 장대한 파국 몽타주로 온다 | 손끝 하나. 거의 아무것도 보여주지 않고, **여왕이 먼저 손을 뺀다** |
