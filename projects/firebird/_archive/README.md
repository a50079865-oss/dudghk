이 폴더의 문서는 **구속력이 없고, 참고자료도 아니다.**
새 작업(`projects/firebird/v2/`)에서 이 폴더를 **열지 않는다.** 이름·설정·지명·인물·설화를 여기서 가져오지 않는다.

## 왜 봉인했나

"캐논은 잊어버리고 첨부터 가"를 실행했다고 보고했으나, 실제 결과물(v2 초안)은 캐논의 **이름·극성·설화 구조를 그대로 승계**하고 지명만 바꾼 것이었다. 감사 결과:

| v2 초안의 요소 | 실제 출처 |
|---|---|
| 엘라라 / 리븐 | `canon/02_`·`03_` — 엘라라 바렌(23) · 리븐 스카엘(27) |
| 북국 = 춥다·군사·규율 | `canon/05_` SKELDRIA |
| 남국 = 강·곡창·왕권·신앙 | `canon/05_` AUREVIA |
| 불새가 사람을 고른다 | `canon/01_` 아우레온의 "인간 증인" |
| 대륙·네 왕국·신수·고대 멸망 | `canon/01_` 에리도르 |

문서를 열어둔 채로는 이 승계를 피할 수 없다고 판단해 **경로에서 치웠다.** 삭제가 아니라 이동이므로 git 이력에 전부 남아 있고, 필요하면 되돌릴 수 있다.
