# SEEDANCE 2.0 — MOTION PRODUCTION RULES

## Core Rule
ONE SHOT = ONE PRIMARY ACTION

## Prompt Order
1. approved identity / location
2. first frame state
3. primary movement
4. camera movement
5. environment reaction
6. final frame state
7. negative motion lock

## Global Continuity Lock
Same approved character identity.
Same facial structure and age.
Same hair length and color.
Same body proportions.
Same costume continuity code.
Same location architecture.
Same weather.
Same time of day.
Same lighting direction.
Same injury and dirt continuity.
Same object placement whenever visible.
No face morphing.
No costume redesign.
No new accessories.
No environmental morphing.

## Negative Motion Lock
- no face morphing
- no identity drift
- no age change
- no hairstyle change
- no costume transformation
- no armor redesign
- no extra limbs
- no duplicate characters
- no sudden 360 orbit
- no extreme fast zoom
- no random slow motion
- no floating movement
- no game animation
- no exaggerated facial acting
- no disappearing architecture
- no melting objects
- no duplicated horses
- no magical glow unless requested

## Elara Motion
- grounded
- practical
- fear can be visible
- no combat-trained stance unless story establishes it

## Riven Motion
- restrained
- minimal gesture
- controlled sword movement
- authority through stillness

## Horse Rule
Use:
- forward walk
- controlled trot
- one-directional gallop

Avoid:
- rearing while running
- spinning
- collisions
- acrobatics

## Crowd Rule
Refugees: layered movement in one dominant direction
Cavalry: coherent formation
Infantry: organized blocks

## Creature Rule
Aureon / Varkaen / Nerysia:
- partial reveal first
- one clear massive movement
- avoid chaotic full-body action
- keep camera stable when scale matters

## Shot Length
- emotional portrait: 3–5 sec
- simple action: 2–4 sec
- myth reveal: 3–5 sec
- trailer montage: 1.5–2 sec
