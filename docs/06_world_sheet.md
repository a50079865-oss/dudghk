# 6단계 결과물: 스타일 / 세계관 레퍼런스 시트

4단계 비주얼 바이블(`04_visual_style.md`)에서 도출한 **제작용 세계관 기준 시트** 사양이다.
무드보드가 아니라, 이후 컷별 이미지·영상 생성에서 배경·색감·조명을 일관 유지하기 위한 기준 문서다.

> **미정 항목** — 작품 제목과 러닝타임은 1·2단계가 없어 비워 두었다. 확정되면 헤더만 교체해 재생성한다.

## 1. 세계관 기본 정보

| 항목 | 내용 |
|---|---|
| 작품 제목 | *미정* |
| 러닝타임 | *미정* |
| 장르 | 실사 중세 하이판타지 |
| 핵심 감정 | 경외와 불안. 억제되어 있으나 깊게 흐르는 정서 |
| 핵심 경험 | 광활한 지형 앞에서 인간이 축소되는 감각, 그리고 안개 속에서 현실감이 녹아내리는 순간 |
| 주요 배경 | 안개 협곡, 이끼 낀 고목림, 로마네스크 석조 성채, 목조 대전, 진흙 전장, 검은 화산 해안, 이탄 늪 |
| 세계의 규칙 | **초자연은 빛나지 않는다.** 마법은 이펙트가 아니라 자연의 이상 현상으로만 드러난다 (§4단계 §8) |
| 상징 요소 | 까마귀 · 사슴뿔 · 매듭 문양 · 불타는 나무 · 안개 속 단독 기수 |
| 피해야 할 방향 | 4단계 §12 전체 승계 |

## 2. 비주얼 스타일 기준 (4단계 반영)

| 항목 | 내용 |
|---|---|
| 아트 스타일 | 실사 라이브액션, 35mm 아나모픽 필름룩 |
| 영상 톤 | 서사적 숭고 → 신화적 몽환 → 육체적 잔혹 |
| 색감 | 저채도 회청 기본, 앰버·심홍은 감정 임계점에만 |
| 조명 | 100% 실광원, 필 라이트 금지 |
| 렌더링 | 아날로그 그레인 + 블랙 프로미스트, 표면에 항상 이력 |
| 캐릭터와의 연결 | 인물 의상의 회청·황토·가죽 갈색이 배경 팔레트에서 그대로 뽑혀 나온다. 인물이 배경에서 튀지 않고 **지형의 일부처럼 읽히는 것**이 원칙 — 5단계 캐릭터 시트는 이 팔레트 안에서만 색을 쓴다 |
| 피해야 할 스타일 | 4단계 §12 |

## 3. 시트 구성

| # | 섹션 | 내용 |
|---|---|---|
| 1 | 메인 세계관 (MAIN WORLD) | 최대 패널. 여명의 안개 협곡, 능선의 로마네스크 성채 실루엣, 지형에 압도된 기수 둘 |
| 2 | 주요 장소 (KEY LOCATIONS) | 썸네일 5 — 안개 협곡 / 이끼 고목림 / 촛불의 회랑 / 진흙 전장 / 횃불의 대전 |
| 3 | 변형 공간 (SPECIAL STATE) | 이상 현상 (바람과 반대로 흐르는 안개, 인광 이끼, 크기가 틀린 실루엣) ↔ 창백한 새벽 (여파) |
| 4 | 상징 오브젝트 (SYMBOLS) | 까마귀 / 사슴뿔 / 매듭 문양 / 불타는 나무 / 안개 속 기수 |
| 5 | 색감 (COLOR) | 6색 + HEX |
| 6 | 조명 흐름 (LIGHTING) | 기본 → 전환 → 위기 → 클라이맥스 4단계 |
| 7 | 환경 앵커 (ENVIRONMENT ANCHOR) | 하단 텍스트 스트립 |
| 8 | 스타일 고정 (VISUAL STYLE LOCK) | 하단 텍스트 스트립 |

## 6. 조명 흐름 ↔ 감정

| 단계 | 조명 | 감정 |
|---|---|---|
| 기본 | 오버캐스트 확산광, 그림자 옅음 | 무기력한 평온, 압도됨 |
| 전환 | 안개 통과광, 방향 불명확 | 방향 상실, 불안의 시작 |
| 위기 | 저각도 역광, 실루엣, 연기 | 임박, 각오 |
| 클라이맥스 | 화염 단일 광원, 앰버 vs 잉크 암부 | 파열, 상실 |

## 7. 환경 앵커 (ENVIRONMENT ANCHOR)

컷별 프롬프트에 반복 삽입할 배경 고정 문장.

```
1. A fog-bound Northwestern European highland at first light or dusk,
   low volumetric mist pooling in the hollows, overcast diffused sky.
2. Recurring built forms: romanesque stone masonry, timber great halls,
   turf-and-daub dwellings, standing stones and burial mounds, beacon cairns.
3. Recurring natural forms: moss-covered ancient woodland, peat bog,
   black volcanic shore, wind-scoured ridgelines.
4. Grade: desaturated slate-grey and moss-green with wet-ochre earth,
   blood-amber only from real fire; practical light sources only.
5. Special state rule: the supernatural never glows — it appears as a natural
   anomaly (fog against the wind, stopped birds, phosphorescent moss,
   a silhouette of wrong scale).
```

## 8. 스타일 고정 (VISUAL STYLE LOCK)

```
1. Photoreal live-action medieval high fantasy, shot on 35mm anamorphic film.
2. Rendering: organic film grain, black pro-mist diffusion, shallow natural
   depth of field, low-key deep shadows, no fill light.
3. Color and light: low-saturation slate-grey base, restrained blood-amber
   accents released only at emotional peaks.
4. Tone: epic scale, mythic stillness, brutal tactile realism —
   awe and unease, never heroic elation.
5. Avoid: game cinematic look, clean new armour, neon magic, oversaturation,
   modern hair and makeup, CGI gloss, overlit night.
```

## 9. 피해야 할 방향 (AVOID)

- 캐릭터 중심 시트로 변질 — 인물은 스케일 참조용으로 작게만
- 장소 간 스타일 불일치 — 여섯 장소가 다른 영화처럼 보이면 실패
- 세계관과 무관한 배경, 동아시아·중동·스팀펑크 이미지 혼입
- 일러스트·3D 렌더·게임 스크린샷 렌더링
- 과도한 UI 패널, 로고, 워터마크, 무작위 문자, 일본어 문자
- 장르 충돌 분위기 (밝고 경쾌한 어드벤처 톤)
