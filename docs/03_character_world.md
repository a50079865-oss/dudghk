# 3단계 결과물: 캐릭터 / 세계관 기획

작품: 「서약의 귀환」 (The Oath's Return) · 60초 · CUT 4

> 외형·의상 디테일·색상 팔레트는 여기서 정하지 않는다 (4단계 확정, 5단계 시트). 이 단계는 **이야기 안에서의 역할과 기능**만 다룬다.

## 1. 캐릭터 설정

### 에드릭 (Edric) — 기사

| 항목 | 내용 |
|---|---|
| 역할 | 주인공. 전장에서 돌아오는 자 |
| 성격 | 과묵하고 완고하다. 감정을 말로 옮기지 않고 약속으로 옮기는 유형. 한번 뱉은 말을 물리지 않는 것이 그의 유일한 자부심이다 |
| 현재 상태 | **본인은 생존했다고 믿는다.** 몸의 통증, 진흙의 무게, 숨의 거침을 모두 느낀다. 그 감각이 그의 믿음을 지탱한다 |
| 사건 속 기능 | 관객의 이동 수단. 그가 걷기 때문에 세계가 순서대로 열리고, 그가 눈치채지 못하기 때문에 긴장이 유지된다 |
| 감정 변화 | 안도(01) → 결의(02) → 의심(03) → 상실(04). 각 단계가 **행동**으로만 표현된다: 일어선다 / 절뚝이며 걷는다 / 뒤를 돌아본다 / 손을 내려다본다 |
| 상징성 | 매듭 끈. 그가 붙잡고 있는 서약 그 자체이며, 그를 계속 걷게 만드는 유일한 동력이자 그를 놓아주지 못하게 하는 족쇄다 |

### 엘스윈 (Elswyth) — 여인

| 항목 | 내용 |
|---|---|
| 역할 | 서약의 상대. 마지막 15초에만 등장한다 |
| 성격 | 조용하고 실용적이다. 울지 않는 사람. 감정을 절차로 처리한다 |
| 현재 상태 | **이미 알고 있다.** 전장의 소식이 그녀에게 먼저 닿았다. 그래서 밤에 촛불을 켜 두고 있었다 |
| 사건 속 기능 | 진실의 확인자. 대사 없이, 촛대를 문턱에 내려놓는 단 하나의 행동으로 결말 전체를 옮긴다 |
| 감정 변화 | 기대(문을 연다) → 확인(빈 안개를 본다) → 애도(촛대를 내려놓는다). 표정 붕괴는 아주 조금만 |
| 상징성 | 촛불. 산 자가 죽은 자의 길을 밝히는 관습의 집행자. 그녀의 슬픔이 곧 그에 대한 마지막 예의다 |

### 까마귀 — 상징적 존재

| 항목 | 내용 |
|---|---|
| 역할 | 세계의 목격자. 인물이 아니라 규칙의 예외 |
| 현재 상태 | 귀로 위에 있다. 산 자도 죽은 자도 아니다 |
| 사건 속 기능 | **세계에서 유일하게 에드릭에게 반응하는 존재.** 관객이 진실을 처음 의심하는 지점을 만든다 |
| 상징성 | 죽음이 이미 그를 세었다는 표식. 날지 않는 것은 도망칠 이유가 없기 때문이다 |

## 2. 세계관 설정

| 항목 | 내용 |
|---|---|
| 기본 배경 | 12~14세기 서북유럽풍 변경. 오래된 전쟁이 끝나가는 계절. 마을과 마을 사이는 안개와 늪으로 끊겨 있다 |
| 숨겨진 세계 | **귀로(歸路).** 별도의 저승이 아니다. 산 자의 세계와 **같은 지형 위에 겹쳐 있는 길**이며, 죽은 자는 자기 죽음을 모른 채 이 길을 걷는다 |
| 세계의 규칙 | ① 초자연은 빛나지 않는다. ② 세계는 죽은 자에게 **거짓말하지 않고, 다만 반응하기를 그친다.** ③ 그래서 진실은 언제나 **무언가의 부재**로만 나타난다 — 소리의 부재, 발자국의 부재, 불꽃 흔들림의 부재 |
| 사건의 원리 | 서약이 강할수록 죽음의 인지가 늦어진다. 귀로는 서약이 데려가는 길이다. 에드릭이 돌아올 수 있었던 이유와, 그가 죽은 줄 모르는 이유가 **같은 것**이다 |
| 분위기 | 경외와 불안. 위협하는 존재가 없는데도 계속 조여드는 압박. 공포가 아니라 슬픔 |
| 상징 요소 | 매듭 끈(서약) · 까마귀(목격) · 촛불(애도) · 안개(귀로) · 발자국 없음(부재) |
| 갈등 또는 변화 | **외부의 적이 없다.** 갈등은 서약("계속 걸어라")과 진실("멈춰라") 사이에서만 일어나고, 진실이 이긴다 |

## 3. 선택 항목

| 항목 | 내용 |
|---|---|
| 에드릭의 욕망 | 돌아가는 것. 이기는 것도 살아남는 것도 아니다 |
| 에드릭의 결핍 | 말로 표현하지 못한다. 그래서 약속에 과하게 의존한다 |
| 관계성 | 오래된 사이. 언어가 필요 없을 만큼 익숙하고, 그래서 마지막 순간에도 대사가 필요 없다 |
| 세계의 금기 | 산 자가 귀로를 알아보면 죽은 자를 붙잡을 수 없다. 엘스윈이 촛대를 내려놓고 **돌아서는** 이유다 |
| 대가 | 귀로를 끝까지 걸은 자는 자기가 어디로 가고 있었는지 알게 된다. 그것이 이 세계가 죽은 자에게 치르게 하는 유일한 값이다 |

## 4. 2단계 시나리오 보정 제안

**① 까마귀를 '규칙의 예외'로 명시할 것 (권장)**
현재 CUT02에서 까마귀는 에드릭을 *응시한다*. 그런데 세계 규칙이 "죽은 자에게 반응하지 않는다"이므로, 응시는 그 자체로 규칙 위반이다. 두 갈래 중 하나를 택해야 한다:
- **(권장) 예외로 확정** — 까마귀만은 그를 본다. 규칙에 구멍을 내는 대신 세계에 깊이가 생기고, 후속편 여지가 열린다. 시나리오 수정은 불필요하고 설정 문구만 추가하면 된다.
- 통일 — 응시를 빼고 완전한 무반응으로. 규칙은 깨끗해지지만 CUT02가 밋밋해진다.

**② CUT01에서 '그가 일어난 자리'를 비추지 말 것**
그가 일어선 자리에 시신이 남아 있는 그림은 관객이 5초 만에 결말을 알아채게 만든다. 카메라가 그 지점을 지나가지 않도록 촬영 지시에 명시하는 편이 안전하다. (반대로 후속편에서 같은 자리를 다시 보여주는 건 강력한 카드다.)

**③ CUT04 엘스윈의 시선을 물리적 지시로 바꿀 것**
"그를 지나쳐서 본다"는 연기 지시라 AI 영상 생성에서 불안정하다. **"문 밖 안개의 한 점에 시선을 고정한다"**처럼 물리적 목표를 주는 편이 결과가 안정적이다. 의미는 동일하게 전달된다.

**④ 매듭 끈의 마지막 처리 (선택)**
설정상 그의 소지품도 함께 귀로를 건너왔다. 마지막에 그가 끈을 **문턱에 내려놓으려 하지만 놓이지 않는** 그림이 지금의 "손을 내려다본다"보다 강하다. 다만 60초에 동작 하나를 더 넣는 부담이 있어, 러닝타임을 늘릴 때 검토할 카드로 남긴다.

> ①~③은 5단계 진행 전에 반영을 권하고, ④는 보류 항목이다.
